# Main board for the two-board starter controller

One main board and one five-button OLED panel connect to one existing 1 HP single-phase starter. The control contacts at J30 and J35 go to the starter. Motor and capacitor current stay in the original starter. Its factory STOP and overload remain in its control circuit. [Schematic PDF](schematic.pdf) · [Editable KiCad project](pump-direct.kicad_pro) · [Parts and cost for one starter](../../output/direct-starter/README.md)

**Main-board change.** This revision deletes the external cabinet feedback connector J54, selector interface J52, feedback relay KFB1 and their support circuits. The redesigned copper supplies the A coil from the normally closed STOP loop on the OLED panel. The arming latch, watchdog and voltage-reset circuitry still control the A driver. B has its own driver so it can issue an electronic STOP after A releases. USB VBUS inhibits both coils. Both replaceable 5 V relays, both diagnostics LEDs, the AC voltage meter, CT input, level and inlet inputs are retained. The panel, small plug-in OLED and optional MANUAL/AUTO key connection at panel J8 use the existing panel design. The layout keeps the previous mounting pattern and 100 × 117 mm outline.

Each relay has two independent control terminals. Use a shared common only where the starter documentation specifies one. The coil voltage, coil inrush, contact suppression and the input wetting current matter. An electronic keypad may use a scanned matrix. The two-board design supports qualified dry-contact interfaces and has no universal assignment for an unknown starter. Identify the actual coil or input first. A relay contact's resistive nameplate rating alone is insufficient for an inductive pilot. [Manufacturer relay and socket data](https://omronfs.omron.com/en_US/ecb/products/pdf/en-g6b.pdf) · [Factory three-wire control principle](https://www.se.com/uk/en/faqs/FA147367/)

**What a stuck contact means.** The factory STOP and overload directly interrupt the conventional contactor coil. If B welds closed while A remains enabled, releasing STOP or resetting the overload can start the motor again. The CT can detect resulting current once the motor runs. It cannot prove the START contact open while the motor is stopped. The panel key changes software mode. A factory-only selector or passive insert physically restores the original circuit; the power link at J41 only selects the board supply. The two-board design provides no independent welded-START restart lockout. An installation that requires this behavior needs it verified in the starter before enabling unattended operation. Isolate the motor and disconnect the two field command plugs for USB bench service. Dropping the command coils cannot stop a self-latching electronic input by itself.

**Programmable voltage.** J1 takes protected AC from the same incoming supply as the pump, ahead of its contactor. The ADE7953 reports voltage to the controller while the motor is on or off. J10 accepts the CT harness around one motor conductor. J20 serves the four tank electrodes plus common. J21 serves inlet water detection. The two existing probe excitation outputs must stay separate. The stocked field connection uses a local inlet sense and return pair. [Panel and sensor field parts](../../output/jlc-r4/field-one-starter.csv)

Initialize this variant through `direct_starter_configure` with the commissioned profile, matched harness settings, calibrated voltage thresholds, independently verified factory shutdown, and real motor feedback. The control cycle reads actual STOP and coil-supply feedback, clears prior authorization when protection drops, and can run without a 24 V cabinet or transfer-position input. In a maintained-RUN installation A alone is requested. The original guarded firmware entry points remain available for their own hardware. Commission the pulse widths, power-return behavior, motor underload limits, probes, controls and radio on the actual build. The repository contains control components and test firmware. A complete field-tested pump application is outstanding.

The main has 226 soldered positions after 46 removals. Main and panel KiCad reports, Gerber connectivity and firmware tests are in the fabrication package. They cover the files and modeled behavior. Enclosure fit with relay clips, fault and voltage tests on the physical starter, mains insulation qualification and EMC remain installation work.
