# Footprint sources

The KiCad board projects include their own symbol and land-pattern tables. The standard land patterns derive from the KiCad 10 library. The controller also uses project-specific drawings for the Omron P6B-04P socket, power converter, ESP32 module, isolation ICs, display connector and panel STOP switch. The manufacturer references are provided in each board's component BOM. Custom model files accompany the individual projects. Install the standard KiCad 10 3D model library to display components that use its STEP files.
