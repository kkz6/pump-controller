Starter integration illustration
================================

The final image follows the reference starter style: two capacitors, a
two-pole contactor, analogue meters, retained START/STOP actuators, one
new MODE button and a small lid OLED. Settings keys are on the PCB.

This is an AI-generated concept illustration, not an installation drawing
or an accurate mechanical fit model. Leader lines identify functional zones;
existing terminals and wire colours have not been assigned. The actual
PCB models and wiring guide are separate deliverables. The proposed carrier
and location require dimensional, insulation and access verification.

The saved edit brief records the final requested visual changes. The source
reference photographs are preserved under design/references.
