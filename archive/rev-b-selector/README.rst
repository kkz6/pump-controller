Rev B selector interface - superseded
====================================

These documents apply to commit dc09030b348e99e8a16620c741da93d69c89426e.
They describe the maintained MAN/OFF/AUTO selector and diode OR path.
Rev C replaces that interface with five momentary buttons and a direct
STOP-return feed to the independent high-high loop. Do not use these
archived wiring diagrams or check counts for Rev C. Native Rev B CAD
is preserved in the referenced Git commit.
