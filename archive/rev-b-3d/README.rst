Superseded Rev B 3D exports
==========================

These files preserve the earlier 208-component board visualization. The
active Rev C model replaces the mode-selector diode pair with two on-board
settings buttons and also has 208 components. Use the Rev C files under ``output/3d`` for the current design.

The models contain approximate project-created package bodies and do not
establish enclosure fit or manufacturing readiness. Coverage and source
board hash are recorded in ``hardware/3d/model-coverage-rev-b.json``.
