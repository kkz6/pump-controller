Superseded LED indicator panel
==============================

This completed 60 x 20 mm, two-layer LED panel is retained as design history.
It was replaced by an I2C OLED module in the active controller design.
The archived board has 17 electrical parts and two mounting holes; its native
KiCad ERC and PCB DRC both report zero violations and zero unrouted nets.
Do not order this board for the OLED version.
