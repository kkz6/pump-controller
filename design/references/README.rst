Starter reference evidence
==========================

starter-interior-reference.png shows the capacitor-equipped control box,
two-pole contactor, lid meter backs/breaker, terminal strip and external RMG
controller. starter-style-reference.png supplies a front-panel style example
and an unverified wiring illustration. Neither establishes the actual coil
voltage, wire identities, capacitor values or insulation/overload arrangement.

Existing operation is reported to start fully automatically in AUTO, without
pressing the starter START button. The provider of capacitor-start engagement
and disconnection remains to be identified before replacing the old controller.

Related primary manufacturer documentation
-----------------------------------------

RMG DFAWLC-044 installation manual (related family, not a confirmed model
identification): https://rmgautomation.com/Downloads/Manual/DFAWLC-044-100101.pdf
Its starter arrangement uses separate relay wire pairs. The RMG catalogue
also distinguishes start/stop and start/run/stop relay variants:
https://rmgautomation.com/Wired_Automatic_Water_Level_Controller

Franklin three-wire single-phase control-box documentation describes starting
relays/capacitors as part of a matched motor control assembly. It is context
for the need to preserve the start circuit, not a wiring diagram for this box:
https://www.franklinwater.com/products/submersible-motors-and-control-boxes/submersible-motor-control-boxes/motor-control-boxes/

The reference image's existing wire colours and schematic labels have not been
adopted as the terminal mapping for the new controller. See the current wiring
guide for source-checked PCB pin numbers and the remaining installation review.
